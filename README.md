# Sreehan Adigopula | Portfolio

A responsive, interactive portfolio built with native HTML, CSS, and JavaScript. No install step, frontend framework, tracker, or external runtime dependency is required.

## Run locally

```sh
npm start
```

Open http://127.0.0.1:4173. Run `npm run check` for syntax verification.

## Features

- Pointer-responsive sculptural hero with an original generated image.
- Project filters and keyboard-accessible project case-study dialogs.
- Keyboard-operable skills tabs and native background accordions.
- Dark and light themes, optional saved theme preference, motion pause, and system reduced-motion support.
- Email links and a copy-email action with a plain fallback.
- Self-hosted open-license fonts and local assets.

## Content and deployment

The deployable website is in `dist/`. It works on any static host. Project content is in `dist/index.html` and `dist/app.js`. Design tokens, layout, and responsive rules are in `dist/styles.css`.

The Sites preview identity is recorded in `.openai/hosting.json`. It is not a credential. `CONTENT_SOURCES.md` documents evidence and editorial choices. `DESIGN.md` records how the three references are combined.

The provided teacher resume is used as background evidence and is not included in the deployed assets. Project screenshots show the real public apps with a fresh local browser state. Do not add personal documents or secrets to `dist/`.
